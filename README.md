# Ethan Moon

I build AI, simulation, and product systems that turn messy real-world signals into useful feedback.

My work sits at the intersection of digital twins, computer vision, realtime coaching, and human-centered engineering. I like projects where the model is not just a demo in a notebook, but part of an experience someone can actually use.

## Featured Work

| Project | What it does | Stack |
| --- | --- | --- |
| [ViolinTwin](https://github.com/emoon0108/ViolinTwin) | Adaptive AI violin practice coach with audio analysis, target imports, and a digital twin profile | Expo, React Native, TypeScript, DSP |
| [Healthy Eaters](https://github.com/emoon0108/HealthyEaters) | Autism-aware nutrition exposure prototype with smart-plate simulation, rewards, mini-games, and low-stim UX | Defold, Lua, BLE prototype |

## Current Interests

- Digital twins for music, sports, bioprinting, and physical systems
- Realtime feedback loops that turn sensor data into coaching or decisions
- Computer vision and geometry for tactical analysis
- Assistive and educational systems that are useful, calm, and humane
- Full-stack product engineering with strong visual presentation

## Tools I Use

Python, TypeScript, React, React Native, Next.js, Lua, Defold, OpenCV, scikit-learn, Expo, Tailwind, simulation workflows, and a lot of fast prototyping.
